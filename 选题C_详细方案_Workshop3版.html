0. 一页纸摘要

问题：临床风险模型在残缺 EHR 上必须先插补再预测。现有共形分诊把插补当作确定性预处理（LOCF），拒识信号只来自预测不确定性；高缺失率下，模型可能“自信地错”，因为插补出来的证据本身不可靠。

主张：插补诱导不确定性（imputation-induced uncertainty）是独立于模型不确定性的风险源；拒识应同时考虑“模型不确定”和“插补不可信”。

方法 MIRAGE：

  1. 按缺失掩码把患者路由到不同插补策略（mean / MICE / GAIN / SAITS / 不插补）；
  2. 用插补器间分歧 + 证据/集成信号，操作性地分离插补不确定性与模型不确定性；
  3. 按掩码分层（Mondrian）校准共形预测集；
  4. 在覆盖率约束下，用成本感知阈值做拒识/转人工。

数据：PhysioNet 2019 主实验；UCI Heart Disease 外部验证；NHANES/原始 BRFSS 可选；CDC 糖尿病仅做模拟缺失补充。

评测：掩码条件覆盖率、最差层覆盖率、选择性风险、risk–coverage、拒识率、临床成本、不确定性错误检测 AUROC。

最近邻：Sci Rep 2026 的 LOCF + CP + cost-aware deferral，作为第一基线直接复现并分析其失效。

撞车率：本方案约 30–45%（中低）；文本查重可压到 <10%。

1.3 为什么它属于“critical application”

  • 脓毒症早期预警的漏诊代价远高于误报；
  • 模型在缺失率高时最需要拒识，而现有方法恰好在此时最不可靠；
  • 拒识不是“逃避”，而是把不确定病例交给更高层级临床判断，符合 critical application 的安全边界。

2.2 摘要草稿（英文，提交时按结果填数字）

Clinical risk models are increasingly deployed on incomplete electronic health records, where missing values must be imputed before prediction. Conformal selective prediction can abstain when a prediction set is unreliable, but existing pipelines treat imputation as a deterministic preprocessing step (e.g., last-observation-carried-forward) and attribute all uncertainty to the model. We argue that imputation-induced uncertainty is a distinct and actionable source of risk: under high missingness, a model may be confidently wrong because the imputed evidence itself is unreliable. We propose MIRAGE, a mask-aware framework that (i) routes each patient to an imputation strategy based on the missingness pattern, (ii) operationally separates imputation uncertainty from model uncertainty using cross-imputer disagreement and evidential/ensemble signals, (iii) calibrates conformal prediction sets per mask stratum, and (iv) defers decisions when imputation uncertainty dominates or the prediction set is not singleton. We evaluate on PhysioNet 2019 and external clinical data under MCAR/MAR/MNAR and missingness rates up to 70%, using LOCF-based conformal deferral as the primary baseline. We report mask-conditional coverage, selective risk, deferral burden, and cost-sensitive utility. The goal is a reliability evaluation protocol that tells clinicians not only when the model is uncertain, but why.

2.3 一句话主张（中文）

现有共形分诊把插补当确定性预处理，拒识只看模型不确定性；我们把插补不确定性显式分离出来，按缺失掩码路由插补并分层校准拒识，在相同覆盖率下降低选择性风险与临床成本。

2.4 贡献点（按重要性排序）

  1. 问题：定义“插补感知的选择性风险”，指出高缺失率下插补误差会被误判为模型误差。
  2. 方法：提出 MIRAGE，把插补路由、不确定性分解、掩码条件 CP、成本感知拒识串成一个可复现框架。
  3. 评测：给出缺失分层的可靠性评测协议（掩码条件覆盖、最差层覆盖、risk–coverage、成本曲线），并在公开数据上与 LOCF+CP 直接对比。
  4. 发现：量化 LOCF+CP 在何种缺失模式下失效，给出失效边界。

3. 问题定义与研究问题

3.1 符号与设定

  • 患者样本：(X_i, M_i, Y_i)，X_i ∈ R^d，M_i ∈ {0,1}^d（1 观测，0 缺失），Y_i ∈ {0,1}。
  • 插补器组合：F = {f_1, ..., f_K}，如 mean、MICE、GAIN、SAITS、none。
  • 路由：k* = g(M, X_obs)，为每个样本选一个插补器。
  • 诊断模型：h(X̃^{k*}, M) → p(y|x)。
  • 共形分数：s(x, y)，如 1 − p_y(x)（LAC）或 APS。
  • 掩码层：m ∈ M（可先聚类，避免组合爆炸）。
  • 预测集：C(x) = {y : s(x, y) ≤ q_m}，q_m 为该层校准分位数。
  • 拒识策略：π(x) ∈ {accept, defer}。

3.2 优化目标

在覆盖率约束下最小化期望临床成本：

min_π  E[ cost(π) ]
s.t.   P(Y ∈ C(X) | M = m) ≥ 1 − α,  for all supported m
       deferral_rate ≤ d_max

成本：

cost = c_FN · FN + c_FP · FP + c_defer · defer

参考量级：c_FN : c_FP : c_defer = 10 : 1 : 2，并做敏感性分析。

5. 方法：MIRAGE

5.1 框架

X_obs, M
   │
   ├─> M1 缺失模式编码：缺失率、块结构、变量类型、模式簇
   │
   ├─> M2 插补路由 g(M, X_obs)
   │       ├─ mean / median
   │       ├─ MICE
   │       ├─ GAIN / SAITS
   │       └─ none（保留掩码）
   │
   ├─> M3 诊断模型 h（LightGBM / MLP）+ 可选证据头
   │
   ├─> M4 不确定性分解
   │       ├─ U_imp：跨插补器/多次插补的分歧
   │       ├─ U_mod：集成分歧或 EDL vacuity
   │       └─ U_al：期望熵
   │
   ├─> M5 掩码条件共形校准（Mondrian CP by mask cluster）
   │
   └─> M6 成本感知拒识
           ├─ set size > 1
           ├─ max prob < τ
           └─ cost-aware threshold（含 U_imp / U_mod）

5.2 M1：缺失模式编码

  • 数值特征：缺失率、连续缺失块长度、变量类型（生命体征/化验/人口学）。
  • 模式表示：M 的二进制向量；高维时用聚类（K-means / 层次聚类）压成 10–30 个 mask cluster。
  • 最小支持度：每个 cluster 至少 n_min 个校准样本（如 50），否则合并到邻近 cluster。

5.3 M2：插补路由

规则路由（先做，稳）：

缺失情况路由
缺失率 < 10%mean / median
10%–30%，变量间相关强MICE
> 30%，高维非线性GAIN / SAITS
整块缺失（如某化验未开）none + 掩码指示

学习路由（加分项，后做）：

  • 输入：缺失率、mask 向量、变量类型；
  • 输出：插补器选择（Gumbel-Softmax / straight-through）；
  • 训练信号：下游验证损失 + 插补误差；
  • 只在训练折内训练，校准/测试不得参与；
  • 必须做“无路由”消融，证明增益不是超参噪声。

5.4 M3：诊断模型

  • 主模型：LightGBM（表格、快、稳）。
  • 备选：MLP / TabNet；不引入大模型，保证 23 天可跑。
  • 可选证据头：EDL，输出 Dirichlet 证据；仅用于 M4 的归因与路由特征，不用于覆盖保证。
  • 类别不平衡：脓毒症阳性率约 7%，用 class weight / focal loss；报告 AUPRC。

5.5 M4：不确定性分解（操作性定义）

不是因果分解，而是可操作的三路信号：

  • 插补不确定性 U_imp：
    • 跨插补器分歧：U_imp = Var_k(p_k) 或平均 pairwise Jensen–Shannon 散度；
    • 或多重插补（M=10）的预测方差。
  • 模型不确定性 U_mod：
    • Deep Ensembles / MC Dropout 的预测分歧；
    • 或 EDL 的 vacuity u = K / S。
  • 数据噪声 U_al：预测分布的期望熵。

主导比：

r(x) = U_imp(x) / (U_imp(x) + U_mod(x) + ε)

r(x) 高表示“这次不可信主要是因为插补”，而不是模型没见过。

验证方式（避免自说自话）：

  • 按缺失率分层，计算 U_imp、U_mod 对“预测错误”的 AUROC；
  • 若 U_imp 在高缺失层显著优于 U_mod，说明分离有意义；
  • 报告二者的相关性，避免完全共线。

5.6 M5：掩码条件共形校准

  • 分层：按 mask cluster m 分别校准。
  • 非一致性分数：LAC s = 1 − p_y，或 APS；主实验用 LAC，附录给 APS。
  • 分位数（有限样本修正）：
q_m = Quantile( {s_i : i ∈ calibration, M_i = m},
                ceil((n_m + 1)(1 − α)) / n_m )
  • 覆盖目标：P(Y ∈ C(X) | M = m) ≥ 1 − α。
  • 小样本层：合并/回退全局，报告覆盖率偏差。
  • 分布偏移：加权 CP（importance weighting）作为扩展，不承诺 MNAR。

5.7 M6：拒识规则

三种规则对比：

  1. Set-size：|C(x)| > 1 → defer。
  2. Confidence：max_y p(y|x) < τ → defer。
  3. Cost-aware（推荐）：在 calibration 上选阈值，最小化 c_FN·FN + c_FP·FP + c_defer·defer。
    • 可加入 r(x) 作为特征：defer if r(x) > ρ and |C(x)| > 1。
    • 约束拒识预算 deferral_rate ≤ d_max。

输出给临床的三件事：

  • 诊断标签；
  • 预测集（可能的类别）；
  • 拒识原因：模型不确定 / 插补不可信 / 两者都有。

5.8 理论主张与边界

命题内容边界
P1impute-then-predict 在可交换性下保持边际覆盖（引 Zaffran et al.）不保证掩码条件
P2按 mask cluster 分层校准，可在每层内给出有限样本覆盖层样本足够；cluster 定义需预先固定
P3成本感知阈值在 calibration 上给出经验成本控制分布偏移下失效；需加权 CP 或在线更新
边界MNAR 下交换性破坏，不宣称保证只报告敏感性分析与失效曲线

5.9 算法伪代码

Input: train D_tr, calibration D_ca, test D_te, portfolio F, alpha, costs
1. Fit imputers F on D_tr only.
2. Fit router g on D_tr (rule-based or learned with inner CV).
3. Fit predictor h on D_tr (with optional EDL head).
4. For each calibration sample:
     m_i = cluster(M_i)
     k_i = g(M_i, X_obs_i)
     p_i = h(f_{k_i}(X_obs_i), M_i)
     s_i = 1 - p_i[y_i]
5. For each mask cluster m:
     q_m = finite_sample_quantile({s_i : m_i = m}, alpha)
6. Choose rejection threshold tau on D_ca by minimizing cost.
7. For each test sample:
     C(x) = {y : s(x,y) <= q_{m(x)}}
     defer if cost_rule(C(x), p(x), U_imp(x), U_mod(x), tau)

6.5 消融

  • 去路由（固定 MICE）。
  • 去 EDL（用 Deep Ensembles）。
  • 去掩码分层（全局 CP）。
  • 去插补不确定性（只用模型不确定性）。
  • 换拒识规则（set-size / confidence / cost-aware）。
  • 插补组合大小（1 / 3 / 5）。
  • mask cluster 数量（5 / 10 / 20 / 30）。

8. 会出现的问题与处理

8.1 撞车类问题

问题严重度处理
Sci Rep 2026 已做“CP + 临床分诊 + 成本延迟”高把它设为第一基线；核心差异写成“插补不确定性归因 + 掩码条件校准”；在 Intro 主动引用
SafeImpute 已做“共形选择插补值”中高明确层级差异：值级 vs 决策级；引用并说明互补
SQUIREDL 已做“EDL + 插补”中EDL 降级为可选模块；主骨架不依赖 EDL
Zaffran 已做“掩码条件 CP 理论”中高引用为理论基线；贡献放在“决策拒识 + 成本约束”，不要重复造理论
审稿人说“这就是 CP + 拒识”高用失效分析开场：LOCF+CP 在高缺失下如何错；再用实验证明差异

8.2 理论类问题

问题为什么会出问题处理
MNAR 下交换性破坏覆盖保证不成立只声明 MCAR/MAR；MNAR 做敏感性分析与失效边界
掩码组合爆炸mask 维度高，层样本稀疏mask 聚类 + 最小支持度 + 合并回退
掩码条件覆盖的有限样本保证每层样本少，分位数不稳报告每层 n、覆盖率置信区间；小层不单独下结论

不确定性“分解”不可识别插补与模型误差纠缠明确是操作性分解，不是因果分解；用错误检测 AUROC 验证
不确定性双重计数EDL + CP 都在用不确定性CP 只用一种非一致性分数；EDL 只做路由/解释；做消融

审稿意见防御
“Incremental pipeline.”用问题定义 + 失效分析 + 掩码条件评测回应；强调不是新模块堆叠

10. 退路

  1. 保守退路：多插补方差 + split CP + 成本拒识。不做 EDL、不做学习路由，仍是一篇完整的“插补不确定性 + 可靠拒识”论文。
  2. 评测型退路：如果方法增益小，改写成“LOCF+CP 在何种缺失模式下失效”的可靠性评测论文，仍契合 workshop 的 reliability evaluation。
  3. 换题退路：转 T2（故障严重度保形回归）。数据全公开、23 天风险最低，但与医疗方向偏离。
