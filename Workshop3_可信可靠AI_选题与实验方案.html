1. Workshop 信息

1.1 主题

AI 正在进入医疗、工业系统、智能制造等关键领域，可靠性、可解释性、鲁棒性与安全性是落地前提。现有模型在面对分布偏移、噪声数据、罕见事件和复杂运行环境时，往往难以解释且性能不稳定。Workshop 关注可解释机器学习、可靠智能诊断、异常与故障检测、不确定性估计、鲁棒学习与可信决策，尤其重视医疗与工业系统。

1.2 关键词

Trustworthy AI；Reliable AI；Explainable AI；Interpretable ML；Healthcare AI；Industrial Intelligence；Fault Diagnosis；Anomaly Detection；Predictive Maintenance；Robust ML。

1.4 投稿偏好推断

  1. 不要求 SOTA，要求可信性问题定义清楚。
  2. 方法与应用并重，纯应用或纯理论都不占优。
  3. 必须有可靠性评测协议，而不只是平均准确率。
  4. reliability evaluation、uncertainty estimation、rare events、distribution shift 是高频审稿关注点。
  5. 有一节诚实的 Failure Analysis，通常比再涨 0.5% 更有说服力。

5. 三个候选选题

5.1 T1（首推）：延迟标签下的保形软测量

工作题目：Calibrated Soft Sensing Under Label Delay: Conformal Prediction with Delayed Feedback

项目内容
命中主席Zhaojing Wang（软测量）★★★；Lei Zhang（不确定性/贝叶斯）★★；Jing Li（可解释）★
数据门槛低，全部公开
算力单卡可选，CPU 可完成主实验
风险中低

空白证据：

  • ASSLD（ISA Transactions 2025）处理标签延迟，但不做保形预测。
  • 保形软测量（IFAC 2025、PMLR v329）假设标签及时到达。
  • 检索 "conformal prediction" "label delay" "soft sensor" 未见直接论文。

核心论点：标签延迟使校准集“过期”，交换性假设被破坏；静态保形在标签返回前覆盖率会系统性失效。这不是工程细节，而是可靠性的前提条件。

方法：

  1. 延迟感知校准更新：按标签到达时间加权/分块入集，样本年龄作为权重。
  2. 在线分位数跟踪：ACI / EnbPI 变体应对过程漂移。
  3. 覆盖率按预测时刻对齐评估，而不是标签到达时刻。
  4. 延迟感知的非一致性分数：可按预测标准差归一化。

数据：

  • Debutanizer column（约 2.4k 样本，7 输入）；
  • Sulfur Recovery Unit（约 10k 样本，5 输入 / 2 输出）；
  • Tennessee Eastman（52 变量，质量变量采样慢，用于半真实延迟）。

写作角度：不卖“新 CP 变体”，卖“延迟反馈下的可靠性保证在什么条件下成立、何时崩溃”。这直接命中 workshop 的 reliability evaluation。

风险：审稿人可能认为只是 CP 的小变体。缓解：给出延迟下的覆盖率分析/命题，并画出失效边界（延迟大于过程时间常数）。

5.2 T2：故障严重度的保形回归

工作题目：Beyond the Label: Conformalized Fault Severity Regression for Reliable Diagnosis

项目内容
命中主席Zhaojing Wang（故障诊断）★★★；Lei Zhang（区间/校准）★★；Jing Li ★
数据门槛低，全部公开
算力低
风险低

空白证据：

  • 严重度估计已有综述（ASME / Manchester review）。
  • 有“分类 + 严重度 + 校准区间”的论文（MDPI Machines 14(10):1171），但区间来自校准集缩放，不是保形。
  • 检索未发现“严重度回归 + 显式保形区间”的轴承论文。

核心论点：诊断回答“是什么”，维修决策还需要“有多严重、估计有多不确定”；分类置信度不能替代严重度区间。

方法：多任务（故障类型 + 严重度回归）+ Mondrian CQR（按故障类型分层校准，解决稀有故障欠覆盖）；区间宽度作为“送检”信号。

数据：CWRU（四档缺陷尺寸）、Paderborn（损伤等级）、XJTU-SY（退化阶段，连续标签）。

写作角度：“一个数字不够”——把严重度点估计升级为带保证的区间，并证明它在维护成本上优于阈值策略。

风险：CWRU 严重度标签只有几档，需要 Paderborn / XJTU-SY 补连续严重度。

5.3 T3：养老跌倒风险的可信筛查

工作题目：Conformalized Fall-Risk Screening for Elderly Care Operations

项目内容
命中主席Wenli Li（养老运营）★★★；Jing Li（医疗/应急）★★；Lei Zhang（医疗数据）★
数据门槛中，NHATS / CLHLS 需申请
算力低
风险中

空白证据：

  • 保形已用于压疮风险（Digital Health）。
  • 跌倒预测有深度学习（Lead-time-aware），但不做保形。
  • 检索未发现“跌倒风险 + 保形/不确定性”的直接论文。

核心论点：风险分数的不确定性会改变护理资源分配；点预测阈值会系统性漏配高风险老人。

方法：风险模型（GBM / Cox）+ 按年龄组、性别、护理等级分组的 Mondrian CP；用风险上界做容量约束下的资源分配。

数据：NHATS（美国，免费注册）或 CLHLS（中国老年健康调查，便于中文语境）。

写作角度：不是“预测跌倒”，而是“资源有限时，不确定性如何改变分配决策与公平性”。

风险：数据申请周期；罕见子群校准样本不足，需要分层策略。

6. 写作角度

6.1 三段式叙事

  1. 代价不对称：关键场景里，漏检一次故障或一次恶化，代价远高于误报；因此“平均准确率”是错误的优化目标。
  2. 失效模式：现有模型在偏移、噪声、罕见事件下过度自信；解释不可验证；校准集过期。
  3. 贡献三点：
    • 方法：不确定性可分解，或区间有覆盖保证；
    • 解释：与领域语义（特征频率、临床指标）对齐，并通过扰动测试验证；
    • 评测：一套包含偏移、噪声、罕见类、选择性预测的可靠性协议。

6.2 标题公式

<失效场景> + <机制> + <可信属性>

示例：

  • Calibrated Soft Sensing Under Label Delay: Conformal Prediction with Delayed Feedback
  • Beyond the Label: Conformalized Fault Severity Regression for Reliable Diagnosis
  • Conformalized Fall-Risk Screening for Elderly Care Operations

6.3 贡献点模板

  • 我们定义了 X 场景下的 Y 失效机制，并给出可检验的刻画。
  • 我们提出 Z 方法，在 A、B 条件下恢复/保证 C。
  • 我们在 D、E、F 三个公开数据集上给出可靠性评测协议，并报告失效边界。

6.4 差异化写法

错误写法：“目前没有相关研究。”（审稿人搜到一篇即否）

正确写法：“最近的工作 [1] 处理了 X，但假设标签及时到达；[2] 在软测量中引入保形预测，但未考虑反馈延迟。本文研究两者交汇处的覆盖率失效问题。”

6.5 Failure Analysis（必须有）

  • 明确写出方法在什么条件下失效；
  • 给出失效边界图（例如延迟超过过程时间常数）；
  • 这比再涨 0.5% 更能获得 critical application 审稿人的认可。

7.3 核心伪代码

for t in stream:
    C_t = weighted_conformal(x_t, calib, alpha_t, weights)   # 只用已到达标签
    emit(C_t)
    for (x_i, y_i, t_i) in labels_arriving_at(t):
        calib.add(x_i, y_i, t_i)
        err = 1 if y_i not in C_{t_i} else 0                  # 关联到预测时刻
        alpha_t = alpha_t + gamma * (alpha - err)             # ACI 更新

关键点：误差必须回填到预测时刻 t_i，不是标签到达时刻；否则覆盖率会被高估。

7.5 基线实现

  • 静态 split CP、CQR：MAPIE 直接调用。
  • ACI：按 Gibbs & Candès 更新式自己实现（约 20 行）。
  • EnbPI：用公开实现或按 bootstrap ensemble 复现。
  • 加权 CP：时间衰减权重 w_i = exp(-lambda * age_i)。
  • 神经基线：MC Dropout、Deep Ensembles（PyTorch，各 5 个种子）。
  • 延迟感知软测量基线：ASSLD 若无官方代码，按论文思路实现简化版，并在文中注明“复现近似”。

7.6 指标定义

  • 边际覆盖率：cov = mean(1[y_t in C_t])
  • 工况条件覆盖率：按工况/负载分段统计，防止边际覆盖掩盖局部失效。
  • 最坏窗口覆盖率：滑动窗口内最小值（安全指标）。
  • 区间宽度：MPIW。
  • Winkler score：同时惩罚宽度与未覆盖。
  • 恢复时间：漂移后覆盖率连续 k 个窗口回到名义值 ± epsilon 所需样本数。
  • 报警成本：cost = c_FN * 漏报 + c_FP * 误报。
  • 校准集陈旧度：标签年龄分布。

7.7 切分与防泄漏协议

  • 时间切分，绝不打乱：train 60% / calibration 15% / test 25%。
  • 校准集与训练集严格不重叠。
  • 滑动窗口特征只使用 t 之前的样本。
  • 超参数只在 train 内交叉验证，test 只看一次。
  • 延迟模拟参数在实验前固定，不允许按结果调整。
  • 报告 5 个随机种子的 mean ± std；方法间做配对 Wilcoxon 检验。

7.8 执行顺序与依赖

E0 数据管道 + 延迟模拟器
  └─> 训练/冻结主干模型（PLS、LightGBM、TCN）
        └─> E1 及时标签基准（门槛：所有方法覆盖约 95%，否则先修管道）
              ├─> E2 固定延迟 ──> E3 随机延迟

7.10 Kill criteria

  1. E2 中静态 CP 覆盖率不下降（例如只掉 1%）：说明模型太稳或延迟太短。加大漂移强度或改用 TE 分析仪延迟；仍不下降则转 T2。
  2. 本方法相对 ACI 提升 < 1% 覆盖率：novelty 不足。补一个延迟下的覆盖保证命题，或转 T2。
  3. 恢复时间没有明显优势：把论文重心从“恢复”改成“失效边界刻画”，仍是可靠评测贡献。
